# Testes de contrato

Espaço para casos de tipos, erros, versões e codecs quando o contrato comum for
extraído. Por enquanto, as duas assinaturas do MVP são verificadas pela suíte
[integration/harbour](../integration/harbour/server_mt.prg), sem duplicar o teste.
Negociação, streaming e os novos formatos continuam pendentes no roadmap.
